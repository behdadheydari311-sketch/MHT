دفتر بستانکاری - پروژه اندروید

=== راه اول: ساخت APK بدون Android Studio، با GitHub ===
(نیاز به نصب هیچ برنامه‌ای روی کامپیوتر ندارد)

۱) یک حساب رایگان در github.com بسازید (اگر ندارید).
۲) روی سایت GitHub، دکمه‌ی سبز "New" را بزنید تا یک مخزن (repository) جدید بسازید؛
   نامش را مثلاً bestankari-android بگذارید و Create repository را بزنید.
   گزینه‌ی "Add a README file" را در این مرحله تیک نزنید.
۳) در صفحه‌ی مخزن تازه‌ساز، لینک "uploading an existing file" را بزنید.
۴) این پوشه (Bestankari) را که از زیپ بیرون کشیده‌اید کامل بکشید و در کادر آپلود رها کنید
   (درگ اند دراپ کل پوشه، نه فقط فایل‌های تک‌تک). مرورگر کروم یا اج را پیشنهاد می‌کنم.
۵) پایین صفحه "Commit changes" را بزنید.
۶) به تب "Actions" در بالای صفحه‌ی مخزن بروید. یک workflow به اسم "Build APK"
   خودش شروع به اجرا می‌کند (چون فایل .github/workflows/build.yml همراه پروژه آپلود شده).
   اگر خودش شروع نشد، روی "Build APK" در لیست سمت چپ کلیک کنید و دکمه‌ی
   "Run workflow" را بزنید.
۷) حدود ۲ تا ۵ دقیقه صبر کنید تا اجرا سبز شود (تیک سبز کنار آن ظاهر می‌شود).
۸) روی همان اجرا کلیک کنید؛ پایین صفحه بخش "Artifacts" را ببینید و
   "app-debug-apk" را دانلود کنید. یک فایل زیپ می‌آید که داخلش app-debug.apk است.
۹) آن فایل apk را روی گوشی اندروید منتقل کنید (مثلاً از طریق تلگرام به خودتان، یا
   گوگل درایو) و نصبش کنید. اگر گوشی هشدار "منبع ناشناس" داد، اجازه‌ی نصب را بدهید.

نکته: این ساخت کاملاً روی سرورهای گیت‌هاب انجام می‌شود و رایگان است؛ نیازی به
نصب Android Studio، SDK یا هیچ ابزار دیگری روی کامپیوتر خودتان نیست.

=== راه دوم: Android Studio (روش قبلی) ===
۱) پوشه را در Android Studio باز کنید (File > Open) و منتظر Gradle Sync بمانید.
۲) گوشی را با USB وصل کنید (USB debugging روشن) و Run بزنید،
   یا Build > Build APK(s) و فایل app-debug.apk را روی گوشی نصب کنید.
۳) بار اول اجازه‌ی «دریافت پیامک» و «اعلان» را بدهید.

=== نحوه‌ی کار اپ ===
هر پیامکی که شبیه تراکنش بانکی باشد (شامل «ریال» و «پرید/نشست/برداشت/واریز») یک اعلان می‌سازد؛
با زدن اعلان، اپ باز می‌شود و فرم با اطلاعات پیامک پر شده است.
